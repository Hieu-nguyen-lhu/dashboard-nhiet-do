Mô tả kết nối thiết bị

ESP32-C3 kết nối qua WiFi và gửi dữ liệu thông số môi trường của tủ thực phẩm trực tiếp lên Dashboard này.

API Endpoint (HTTP POST)

Mã nguồn ESP32 gửi dữ liệu dạng JSON thông qua phương thức POST:

POST http://[Dashboard_IP]/api/data

JSON Data Payload

{
  "temp": 2.4,        // Nhiệt độ DHT22
  "hum": 62,          // Độ ẩm DHT22
  "door": 0,          // 0 = Đóng, 1 = Mở (Cảm biến từ NC)
  "current": 0.05     // Dòng điện ACS712 (A)
}

Cấu hình chân nối trên ESP32-C3

Linh kiện Chân nối ESP32 Chức năng
DHT22 GPIO 4 Đọc Nhiệt độ / Độ ẩm
Cảm biến từ NC GPIO 5 (PULLUP) Đóng / Mở cửa tủ
ACS712 GPIO 2 (ADC) Đo dòng điện làm lạnh
Còi Buzzer 5V GPIO 7 Báo động tại chỗ (HIGH = Kêu)
